TAB-LE
  A new tab page thats literally a table.

  Welcome to TAB-LE. This isn't just a generic new tab page, it's a table. A table that you can customize with widgets, sticky notes, and more

  Features:
  - Add widgets like a clock for time, a calendar for dates, a timer for focus and lot more widgets to come.
  - Add sticky notes to jot down your thoughts and ideas.
  - Add links to your favourite websites and search the web with your preferred search engine.
  - Change the wood texture of the table to match your style.
  - Change the theme of the page to light, night or dark mode.
  - Saves your changes automatically so you can pick up where you left off.
  - Works offline and doesn't track you. Your data is stored locally in your browser and never leaves your computer.

  Built with:
  Html5 - For structure and content of the page. 
  CSS3 - For styling and layout of the page. All the design works.
  Javascript - For interactivity and functionality of the page. All the logic and data handling were done with javascript.

  Try it yourself and see how it works at tab-le.vercel.app. You can also check out the source code in this github repository and contribute to the project if you want to add new features or improve existing ones.

  How to use it?
  - To use tab-le go to the link and you will see a table with a few widgets and sticky notes already added. 
    You can click on the widgets and sticky notes to interact with them. Right clicking on the widgets will rotate them. 
    Dragging the widgets will move themDouble clicking a lamp in night mode will turn it on/off.
    Click on the sticky notes/todo lists to edit them. You can also add new widgets and sticky notes by clicking on the add widget button.
    You can also change the wood texture, search engine of the table by clicking on settings.
    You can also change the theme of the page.

  Have fun navigating through the table and customizing it to your liking.
